# Справочник API проекта

> Здесь только ОПИСАНИЕ сервисов. Сами ключи — в `.env` (он в `.gitignore`).
> Шаблон имён — в `.env.example`.

### Anthropic (Claude) — пример
- Зачем: генерация текстов
- Переменная в .env: `ANTHROPIC_API_KEY`
- Где получить ключ: https://console.anthropic.com
- Лимиты/цена: оплата за токены, поставь лимит расходов в кабинете
- Где используется: `src/lib/ai.ts`
